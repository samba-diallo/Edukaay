# EduKaay - Main Branch (Production)

## 📌 Statut

Cette branche est **réservée pour les versions de production** finales.

## 🔄 Workflow

- **`main`** : Versions de production stables uniquement
- **`dev`** : Développement actif et tests

Les changements sont fusionnés vers cette branche **uniquement** via des Pull Requests depuis `dev` après tests complets.

## 📦 Releases

Les releases de production seront taggées ici :
```bash
git tag -a v1.0.0 -m "Production release v1.0.0"
git push origin v1.0.0
```
